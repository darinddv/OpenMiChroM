# openMiChroM Tutorials

These tutorials provide **conceptual, methodological, and research-grade guidance**
for using openMiChroM to study chromatin structure and energy landscapes.

## Philosophy

- API documentation lives in the official Read the Docs site.
- These tutorials focus on **why**, not just **how**.
- Energy landscapes, rare events, and scientific interpretation are first-class topics.

## How to use this guide

- New users should start with the **Foundations** section.
- Advanced users can jump directly to **Energy Landscapes** or **Rare Events**.
- No tutorial modifies openMiChroM’s core model.
